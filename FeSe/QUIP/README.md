這裡是說明QUIP如何去進行訓練，我通常直接在終端機上執行指令，目前會視情況使用3種描述符(distance_2b,angle_3b,SOAP)
重要參數筆記
n_sparse設定最好小於數據數*每筆原子數*0.1，以避免過擬合，這個參數是用來告訴QUIP能用多少的數據來訓練，我的理解是每個原子都可以當成一個可以選擇的數據點；n_sparse需求量:distance_2b<angle_3b<SOAP，distance_2b大約用70內就夠了，angle_3b大約200左右，SOAP可能需要700以上
cutoff最好設定L/2，L為最小邊長，這表示描述符可以看到多遠的距離，數值越大越需要更多的n_sparse
e0是表示孤立原子的能量，通常以超大晶格放單一原子(a,b,c=15，原子放置於正中央)，來取得孤立原子的能量
default_sigma表示有多信任數據之不確定性
