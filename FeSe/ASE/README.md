我通常使用ASE進行創建晶體不同的結構
目前針對只使用能量計算我建議：
1.先用strain.py的檔案創建一些strain結構並計算能量
2.利用create_xyz.py寫出結構與能量，寫成QUIP可接受的xyz檔，並移動至QUIP資料夾進行訓練，並找出計算的最低能量，並找出目前的relax晶體結構之原子位置與晶格常數
3.利用rattle.py進行創建隨機位移的結構，並計算能量，之後重複步驟2找出目前relax的晶格之原子位置與晶格常數，這一步是為了盡可能接近計算法真實的relax結構，用來確保之後所生成的結構是基於relax的位置，來讓數據的效率最高
4.找出relax結構使用shear.py來生成shear的結構
5.利用phonopy_disp.py可以依據當前的對稱性，生成之後計算聲子會用到的結構
